# Tools

Helper scripts for maintaining the demo repository.

## build-diagrams.py

Regenerates the 9 Excalidraw skeleton files in `../diagrams/` from code. Useful if you tweak the palette or layout and want consistent regeneration.

```bash
python3 build-diagrams.py
```

Output goes to `../diagrams/*.excalidraw`. Open them in Excalidraw to refine.
